copy of runtime with `pnpm install --frozen-lockfile --ignore-scripts`, then `pnpm lint`,
`pnpm typecheck`, and `pnpm test`. Real-service checks: `just test-explorable-document-live`.
Detailed local logs, screenshots, authoring candidates, and sample metadata are retained
in the task's ignored playground session. Hosted CI has been configured but not run.

## Limitations retained

- Native Safari coverage is render smoke only; Chromium owns automated interaction evidence.
- Other operating systems and remote harness process lifetimes have not been validated.
- iframe/CSP isolates viewer privileges; it does not promise hostile-code zero-egress or CPU containment.
- Evidence is hash-bound but not cryptographically attested. MDX expressions need browser checks beyond TS/TSX type checking.
- Light-mode visual styling is an authored interpretation, pending human taste review.

## Deferred

As listed in the PRD: live agent continuation, protocol adapters, external services,
single-file export, automatic draft restoration, registry installation, and release.
