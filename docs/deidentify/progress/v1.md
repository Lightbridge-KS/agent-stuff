# deidentify v1 — progress

Design (the decision): [`../design.md`](../design.md) — approved 2026-08-28 (KS).
Bundled deterministic CLI (`deid.py`) over Presidio's SDK; agent supplies the judgment;
local-only invariant. Seeded from Claude plan `cached-greeting-kazoo`.

Origin: KS wanted an agent-driveable "scan this file for PHI, flag, anonymize" over
text/JSON/CSV/images/DICOM; upstream `presidio-cli` can't anonymize and exits 0 on
findings, so a cheatsheet alone would leave the agent hand-writing SDK scripts on PHI.

## Deferred

- XLSX input (needs openpyxl; CSV covers v1).
- `--fast` regex-only mode (`NoOpNlpEngine`) for code/config scanning.
- Upstream: `presidio-cli` exit-code bug (`show_problems` never assigns `max_level`) and
  `presidio-image-redactor` crashing on `allow_list=None` — candidate upstream PRs.
- Realistic surrogates (Faker names) instead of `<PERSON_1>` — only if a use case asks.
- Thai addresses / sub-districts: no recognizer; LLM catches full addresses as `LOCATION`
  inconsistently. `patterns:` per document for now.
- LLM determinism: the same note can drop a span between runs (`Extraction missing
  char_interval`). Surface, don't hide; a second pass or a pattern covers it.

## Confirmed contracts

- Exit codes `0/1/2/3` as in design.md; 1 also means *leaks* for `verify`.
- Sidecar `version: 1`; required for `pseudonym`/`encrypt`, optional for `date_shift`; carries
  the policy's `operators` table so restore never needs the policy file; the reverse operator
  table never contains `keep` (presidio's deanonymizer has none).
- Freshly installed skills appear in a running session's Skill list only after its next tool
  call (harness registration quirk, same as subagents) — a smoke needs one Bash call first.
- Structured typing = coverage heuristic (60 % hit, 80 % coverage) + `columns:` override;
  column name / key path passed as presidio `context`; placeholders never re-flagged.
- Image path must pass `allow_list=[]`, never `None` (presidio-image-redactor iterates it).
- Presidio versions pinned in the header: analyzer/anonymizer 2.2.364, image-redactor 0.0.60,
  spaCy 3.8.x + `en_core_web_lg` 3.8.0 wheel; Python `<3.14`.
