# deidentify v1 — progress

Design (the decision): [`../design.md`](../design.md) — approved 2026-08-28 (KS).
Bundled deterministic CLI (`deid.py`) over Presidio's SDK; agent supplies the judgment;
local-only invariant. Plan file this was seeded from: Claude plan `cached-greeting-kazoo`.

Origin: KS wanted an agent-driveable "scan this file for PHI, flag, anonymize" over
text/JSON/CSV/images/DICOM; upstream `presidio-cli` can't anonymize and exits 0 on
findings, so a cheatsheet alone would leave the agent hand-writing SDK scripts on PHI.
