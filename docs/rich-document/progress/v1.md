## Confirmed contracts

- One agent-authored `.qmd` document; versioned subset, not unrestricted Quarto.
- Quarto 1.9.38 is required; default saving uses the Lightbridge resolver.
- Both accepted themes ship with a toggle; dark surfaces are neutral near-black.
- No countdown, idle timeout, lifetime cap, or activity heartbeat for the viewer.
  Tab closure ends viewing; explicit stop or process shutdown ends the server.
- Source and rendered output persist independently of the original source file.
- Syntax parsing uses the bundled Mermaid parser; rendering retains its strict sanitizer.
- Displayed shortcode/code examples survive Quarto preprocessing as literal content.
- No executable examples, feedback collection, arbitrary generated CSS/JS, or MCP in v1.

## Verification limits

- Direct standalone `file://` viewing was blocked by the available browser policy.
  Embedded resources and saved HTML are verified; file-origin interaction is not.
- Exact clipboard round-trip, physical print/PDF pagination, other operating systems/harnesses,
  and the complete Mermaid diagram catalog remain unverified.
- Browser theme preference is origin-scoped: a new viewer port starts from the OS
  preference. Quarto's Safari theme switch can reset scroll position. File exports
  do not retain explicit theme choice across reopenings.
- Temporary output is removed on normal stop; abrupt process termination may
  leave temporary files. Saved artifacts have no automatic retention cleanup.
