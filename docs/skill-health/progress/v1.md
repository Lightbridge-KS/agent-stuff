## Confirmed contracts

Established by testing during the v1 build; these now bind the implementation.

- **launchd cannot use the `uv` shebang.** Verified: `env -i PATH=/usr/bin:/bin
  skill-health` → `env: uv: No such file or directory`. The plist must invoke
  `~/.local/bin/uv` by absolute path, or the job silently never starts. Pinned by the
  template's comment; the in-tool PATH augmentation covers the checkers, not the launch.
- **`launchctl load` is dead on this macOS** — fails `Input/output error` even on a
  `plutil`-clean plist. `launchctl bootstrap gui/$UID <plist>` works. Docs updated.
- **A checker missing from PATH is red, not skipped.** It was meant to run and did not,
  so its surface is unverified; skipping would report health the tool cannot vouch for.
  An absent *sibling tree* is genuinely skipped — a clone elsewhere has no private castle.
- **A failing notifier never changes the verdict.** The checks already answered; the
  notifier failure goes to stderr and the exit code stands.
- **`metadata` values are strings** — the watchdog's `Alert.Metadata` is
  `map[string]string`, and a shared notifier would fail to unmarshal anything else.
