# generative-ui v1 — progress

Design (the decision): settled in session 2026-09-02 (KS), no separate design doc — the skill
body *is* the design; sources and lessons in `plugins/experiment/skills/generative-ui/references/sources.md`.
Learning workspace with transcripts, slide sheets and per-talk notes: `~/Movies/YouTube/Gen-UI-VDO/`.

Origin: KS watched three generative-UI talks and asked what skill would carry the distillation.
Gap identified: existing lenses cover the surface an agent *drives* (`ax-interface`,
`surface-architecture`) and the organs inside it (`agentic-architecture`); none covers the
surface an agent *emits*.

## Decisions (resolved 💡)

- **Kind / home:** Concept skill (+ dated Reference appendix), Authored, `plugins/experiment/generative-ui/`.
  Not a fourth `-architecture` lens: content compresses to three tables and two checklists.
- **House defaults encoded in the skill:** clinical or deterministic result surfaces → Controlled only;
  analytics/exploration → Declarative; Open-ended never touches PHI. Stated as defaults, overridable per project.
- **Acceptance test:** by hand for v1, three scenarios, with-skill vs bare, recorded in
  `_playground/2026-09-02_generative-ui-acceptance/NOTES.md` (gitignored; findings summarised below).
