# ask-form v1 — progress

Design (the decision): [`../design.md`](../design.md), written at step 5 once the contract survived
contact; until then the approved plan is the design (Claude plan `wiggly-noodling-flamingo`,
2026-09-03). Tier placement per `generative-ui`: Declarative question blocks against a fixed catalog,
Controlled chrome, Open-ended excluded.

Origin: KS wanted a richer Q&A channel than `AskUserQuestion` / `request_user_input` (sliders,
ranking, matrix, long text, diagrams to react to, per-item approve/reject). Spikes
(`_playground/2026-09-03_ask-form-spike/NOTES.md`): Claude Code's sandboxed shell can bind loopback
and launch the browser; Codex can bind but not launch → CLI-first, print-the-URL fallback, MCP deferred.

## Decisions (resolved 💡)

- Name `ask-form`; catalog v1 = ten types; answers on stdout only; agent may use it whenever it sees
  fit ("if AskUserQuestion can carry it, use AskUserQuestion").
- Theme follows system; one scrolling page with sticky submit bar; glassmorphism, revised to monochrome shadcn-style with semantic color only; mermaid lazy from cdnjs.
- No default timeout (KS): the run waits for Send or Cancel; the skill runs the CLI in the background.
- CLI bundled **inside the skill** (`<skill_dir>/scripts/ask_form.py`), the deidentify shape.
- `review` default decisions `approve | revise | reject`; Cancel returns nothing (plan defaults, unchallenged at approval).

## Confirmed contracts

- Exit codes: 0 submitted · 1 cancelled (or timeout with `--timeout`) · 2 invalid spec or usage · 3 could not bind.
- No timeout by default; the skill runs the CLI in the background. Theme: monochrome shadcn-style glass, semantic color only (KS, 2026-09-03).
- stdout is exactly one JSON document per run; the URL is the first stderr line, flushed.
- Token gates `/`, `/asset/N`, `/submit`, `/cancel`; `/static/*` is open. Second terminal POST → 409.
- Closing the tab ends nothing; Cancel or Send does. Browser-launch failure is not an exit: print the URL, keep waiting. macOS launches via `open`, not `webbrowser`.
- Vendored: marked (MIT), DOMPurify (Apache-2.0 / MPL-2.0); `img` forbidden in markdown.
