# Credits

The body-filling rules and `references/body-shapes.md` adapt Matt Pocock's
[`pr`](https://github.com/mattpocock/skills/tree/main/skills/in-progress/pr) skill,
whose visual catalog is in turn Dex Horthy's
[`show-me`](https://github.com/humanlayer/skills/blob/main/plugins/show-me/skills/show-me/SKILL.md)
(HumanLayer), aimed at a diff instead of a live conversation. The content is copied
rather than referenced so the skill installs standalone; this file carries the
attribution a dependency would otherwise have carried. Adapted here: the fixed
three-section template is dropped in favour of the structure GitHub resolves, the
evidence tiers assume `gh` (no image upload), and a merge-risk line and a
`Deferred:` bullet are added.
