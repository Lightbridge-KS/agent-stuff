# Lens: reproducibility

Can durable work in the candidate be used without the author's machine or session?

Read both skill files named in the packet — `reproducible-codebase` for code and
scripts, `write-for-the-clone` for documentation — and apply each where relevant.
Without them this lens is partial.

- Check that documented commands and configuration correspond to the implementation
  in the candidate.
- Identify dependencies on files, tools, or settings absent from the declared setup.
- Respect declared platform support, valid domain constants, scoped historical
  evidence, and exploratory or illustrative exceptions. A location alone does not
  decide whether work is durable.
- Do not demand configuration, containers, or platform support nobody declared.

Evidence: the hidden assumption or the missing context, and the supported environment
or intended reader it fails.
