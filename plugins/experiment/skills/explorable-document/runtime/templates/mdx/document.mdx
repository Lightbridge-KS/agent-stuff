# When does a queue stop keeping up?

Arrivals and service capacity share one small model. Change either rate to see
both the diagram and the explanation update. This is an **illustrative steady-state
M/M/1 queue**, not a forecast: arrivals are Poisson, service times exponential, and
there is one server. All rates use jobs per minute.
